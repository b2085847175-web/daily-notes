### 设置全局变量

- 全局变量用 `g_context` 类管理
- `_dic` 是类变量，不同地方访问时可以共享同一份数据

定义全局上下文：

```python
class g_context:
    _dic = {}

    def set_dict(self, key, value):
        self._dic[key] = value

    def set_by_dict(self, dic):
        self._dic.update(dic)

    def get_dict(self, key):
        return self._dic.get(key, None)

    def show_dict(self):
        return self._dic
```

设置单个变量：

```python
g_context().set_dict('URL', 'http://shop-xo.hctestedu.com')
```

批量设置变量：

```python
g_context().set_by_dict({
    'URL': 'http://shop-xo.hctestedu.com',
    'NAME': 'youyi'
})
```

读取变量：

```python
url = g_context().get_dict('URL')
all_data = g_context().show_dict()
```

从 `context.yaml` 加载全局变量：

```python
import yaml

def load_context_from_yaml(file_path):
    yaml_file_path = file_path + '/context.yaml'
    with open(yaml_file_path, 'r', encoding='utf-8') as file:
        data = yaml.load(file, Loader=yaml.FullLoader)
        if data:
            g_context().set_by_dict(data)
```

`context.yaml` 示例：

```yaml
URL: http://shop-xo.hctestedu.com
NAME: youyi
```

- 注意：需要变化的数据，比如环境地址、账号、token 等，适合放全局变量

### 按照变量模板格式使用全局变量

- 在 Python 里，直接用 `get_dict` / `show_dict` 取全局变量
- 在 YAML 里，不直接写真实值，用 `{{变量名}}` 占位
- 执行前用变量渲染，把 `{{URL}}` 替换成全局变量里的真实值

YAML 中使用：

```yaml
请求地址: '{{URL}}'
请求数据:
  accounts: '{{NAME}}'
```

安装变量渲染库：

```bash
pip install jinja2 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

渲染方法：

```python
import json

from jinja2 import Template


def refresh(target, context):
    if target is None:
        return None

    if isinstance(target, (dict, list)):
        target_str = json.dumps(target, ensure_ascii=False)
    else:
        target_str = str(target)

    return Template(target_str).render(context)
```

执行用例时，先拿全局变量，再渲染：

```python
import copy

context = copy.deepcopy(g_context().show_dict())
step_value = eval(refresh(step_value, context))
```

渲染效果：

```text
全局变量：{'URL': 'http://shop-xo.hctestedu.com', 'NAME': 'youyi'}
YAML 写法：'{{URL}}'
渲染后：'http://shop-xo.hctestedu.com'
```

- 注意：`{{变量名}}` 只是模板写法，真正取值时要把全局变量字典传给 `refresh`

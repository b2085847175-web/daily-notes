# 9月3号 课堂笔记

### 接口自动化为什么操作数据库

- 断言：接口返回结果和数据库里的数据校验（更严谨）
- 准备数据：接口执行前从数据库取数据
- 检查：新增 / 修改 / 删除是否正常操作了

### Python 操作数据库

- 安装：`pip install pymysql -i 镜像`
- 操作步骤：
  1. 连接数据库
  2. 创建游标（类似鼠标，执行 SQL 获得结果）
  3. 写 SQL 语句
  4. 游标执行 SQL
  5. 游标获得结果
  6. 游标关闭
  7. 数据库连接关闭

### 框架里封装数据库断言

- 数据库信息不能写死（经常变），写在 `context.yaml`
- SQL 语句也不能写死
- 封装成「提取数据库MYSQL」关键字
- 查询可能返回多条数据，用变量名 `_1`、`_2`… 区分
- 变量名可以不写，不写就用原始字段名 `_xx`

# 9月8号 课堂笔记

### 为什么用 Excel

- 工作中：会 YAML 用 YAML，不会 YAML 用 Excel
- 面试 / 工作任选一种用例格式
- Excel 对测试人员更方便，不需要记 YAML 规则，按 Excel 标准写即可
- 用例在本地写好，复制进来

### Excel 用例规则

- 固定必须的列
- 操作类型根据 keywords 来，一个用例可以有多个步骤

### 核心问题与解决思路

- 框架目前不能运行 Excel，怎么才能运行？
- 思路：读取 Excel 数据，转成和 YAML 一致的格式，框架就能运行（改动最小）

### 目标

- 把 Excel 数据读出来，读成和 YAML 一样的格式

YAML 格式分析：

```yaml
基础配置:
  用例类型: xxx
  用例标题: xxx
  一级模块: xxx
  二级模块: xxx

用例步骤:
  - 测试步骤1:
      操作类型: xxx
      数据内容
  - 测试步骤2:
      操作类型: xxx
      数据内容
```

### 安装库

```bash
pip install pandas -i 镜像
pip install openpyxl -i 镜像
```

### 解析规则

- 同一个用例标题 = 同一个测试用例，可以有多个步骤
- 循环用例时：标题有值就是一条用例；没有标题的追加到用例步骤里
- 最终效果：Excel 数据转换成和 YAML 一样的结构

## 四、requests 的两种请求方式
- `requests.request(method, url, **kwargs)`：通用方式，method 指定 GET/POST 等
- `requests.get(url)`：发送 GET 请求
- `requests.post(url)`：发送 POST 请求

## 五、GET 和 POST 的区别

GET 方式（参数带在 url 后面）：
```
/dangdang/user/login?user.email=123@qq.com&user.password=123456
```

POST 方式（表单方式提交，参数放请求体里）：

| 对比项 | GET | POST |
|--------|-----|------|
| 安全性 | 不够安全，数据带在 url 后面 | 更安全，数据放在请求体 body 里 |
| 数据大小 | 有限制（约 1KB） | 无限制 |
| 主要用途 | 查询 | 增删改 |

## 六、POST 请求的参数类型：data / json / params
- `params`：公共参数，拼在 url 后面（如 `?application=app`）
- `data`：表单格式提交（application/x-www-form-urlencoded）
- `json`：JSON 格式提交（application/json）
- `headers`：请求头，用于传 Content-Type、Authorization 等

传参位置总结：
- `params` → 放在 url 上
- `data` / `json` → 放在请求体 body 里
- `headers` → 放在请求头里

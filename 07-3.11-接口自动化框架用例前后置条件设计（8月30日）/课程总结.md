# 第07课｜3.11 接口自动化框架用例前后置条件设计

- 学习日期：8月30日
- 课程阶段：Pytest/YAML 框架搭建

## 本节核心内容

- 前置脚本准备数据、后置脚本清理数据。
- 脚本里的 `context` 就是全局变量字典；`context.update()` 往全局变量里加值。
- YAML 中 `前置脚本`、`后置脚本` 可以写空字符串或列表。
- 执行顺序：全局变量 → 前置脚本 → 渲染步骤 → 接口请求 → 后置脚本。
- 用 `run_script.exec_script` 动态执行脚本。

- `HAT/core/TestRunner.py`

# 9月11号 课堂笔记

### 什么是接口 Mock

- 接口 Mock（模拟）：真实接口未开发完成、无法调用时，创建一个模拟服务，返回预设的假响应数据，供前端调试、接口测试使用
- 关键词：模拟假响应数据
- 应用场景：后端接口没写好、第三方接口用不了、支付接口、短信接口

### Mock 开发需要知道

- 接口地址
- 请求方式
- 请求参数
- 正常返回什么数据
- 异常返回什么数据

### Mock 方式对比

- Flask：轻量、代码少、易扩展、支持 GET/POST/JSON
- Django：重量级、功能全

### Flask 最核心格式

```python
from flask import Flask

app = Flask(__name__)

@app.route('/mock/test', methods=['GET', 'POST'])
def mock_test():
    return {"code": 200, "msg": "Mock接口调用成功", "data": "测试数据"}

if __name__ == '__main__':
    app.run(debug=True, host='0.0.0.0', port=8888)
```

可以变化的：

- 接口地址：`/mock/test`
- 请求方式：get / post（任选一种或两种）
- return 接口返回结果
- `debug=True`：代码修改后自动重启
- `host='0.0.0.0'`：局域网访问地址
- `port=8888`：端口号

### 参数获取

- GET 获取参数用 `request.args`
- POST 传参用 `request.data`
- JSON 数据用 `request.json`

### 注意

- 做假接口的目的就是模拟数据：真实返回数据、错误返回数据
- 一定要和接口文档一致

# 9月10号 课堂笔记

### 发现的问题

- 框架支持 YAML 用例，也支持 Excel 用例
- 但每次都要跑到 `TestRunner.py` 里改用例数据、用例路径、调用方法
- 麻烦，其他人也不敢动，怕改错

### 解决：自定义插件

- 不改变框架原有逻辑，给 pytest 加自定义功能
- 让命令行传参，在 main.py 写明要运行什么用例、路径在哪

### Pytest 插件是什么

- Pytest 插件 = 给 Pytest 加功能的 Python 模块，能干三件事：
  1. 扩展功能（如加 `--type`、`--cases` 参数）
  2. 修改行为（改变默认执行流程）
  3. 集成工具（日志、重试、报告）

### 钩子函数（Hook）

- Pytest 提前定义好的「执行节点」
- 比如：用例收集前、用例执行前、命令行参数添加时

### 核心钩子

1. `pytest_addoption`：给 Pytest 添加自定义命令行参数
   - `--type`（用例类型）、`--cases`（用例目录）、`--keyDir`（扩展关键字目录）

2. `pytest_generate_tests`：动态参数化测试用例
   - 收集用例时自动调用，在这里动态给测试用例传数据

3. `pytest_collection_modifyitems`：解决中文显示乱码

### 命令行运行

- 去掉 main.py 里写死的用例路径和 `@pytest.mark.parametrize`
- 改为命令行运行：

```bash
huace-test --type=yaml --cases=./examples/api-cases-商城
```

### 框架打包

1. 创建虚拟环境，把 examples 和 HAT 放进去
2. `pip freeze > requirement.txt` 导出依赖
3. `pip install -r requirement.txt -i 镜像` 安装
4. main 文件内容更改
5. 增加 `setup.py`、`README.md`、`allure_combine`（complete.html）
6. `python setup.py install`
7. 报 no module 用 `pip install -e .`

# 9月2号 课堂笔记

### 为什么需要深度断言

- 普通的断言（取某个字段比对）不能深度判断整个结果是否符合预期
- 预期结果：`{"msg":"查询成功","body":{"id":"1","name":"youyi"}}`
- 实际结果：`{"msg":"查询成功","body":{"id":"1","name":"youyi"}}`
- 只取某一个值断言，其他字段没校验到

### deepdiff 深度断言

- 安装：`pip install deepdiff -i https://pypi.tuna.tsinghua.edu.cn/simple/`
- 作用：对整个结构做深度比对
- 能解决普通 `==` 断言失败的情况：
  - 大小写不一致（如 name 的 `Youyi` vs `youyi`）
  - 字段顺序不一致
  - 动态数据（如 token、时间戳）需要过滤掉
- 用法：根据需求写预期结果，忽略大小写、忽略顺序、过滤动态字段

### 框架里的应用

- 用例运行完后：拿预期结果、实际结果做深度断言
- 深度断言同样封装成关键字（见 `examples_test/deepdiff1_test.py`、`deepdiff2_test.py`）

# 9月7号 课堂笔记

### 常用案例：上传、下载、加密接口

- 上传接口：把内容（图片/文件）上传到服务器
- 下载接口：把服务器的内容下载下来
- 加密接口：登录需要加密数据，只能传加密数据

### 上传 / 下载接口

- 上传和下载的服务启动后不能关闭
- 测试上传接口四要素：
  - 请求方式：post
  - 地址：`http://127.0.0.1:5000/upload`
  - 文件：`files={'image': open('login1.csv', 'rb')}`
  - 响应结果

### 加密接口

- 加密每家公司不一样，代码没有通用参考价值，了解即可
- 接口测试遇到加解密，要根据公司规则加解密，需要了解加解密算法

加密过程：

1. 用户在前端输入用户名和密码
2. 前端把明文密码加密成密文
3. 发送请求，密文发给后端接口
4. 后端用对应算法解密成明文

### 接口测试加解密的方式

1. 开发直接生成加密 / 解密数据，拿来做测试
2. 开发提供 API 调用方式，把加解密打成 jar 包

```
java -jar encryption-util-1.0.0.jar encrypt "mypassword123"
java -jar encryption-util-1.0.0.jar decrypt "密文"
```

3. 用外部加解密工具
4. 了解开发加解密规则，自己写代码加解密

### 常见的加解密类型

- 对称加密：des、aes、base64（同一个密钥）
- 非对称加密：rsa、dsa、ecc（公钥 + 私钥）
- 哈希：md5、SHA 系列（不可逆，不能解密）

### 访问加密接口的准备工作

- 拿到 jar 包
- 在 jar 目录运行：`java -jar api-project.jar`（加密服务要运行起来）
- 浏览器访问：`http://127.0.0.1:8080/doc.html`
- 安装库：`pip install pycryptodome -i 镜像`
- 加密四要素：接口地址、参数（username/password）、请求方式 post
- 发请求之前先把数据加密好

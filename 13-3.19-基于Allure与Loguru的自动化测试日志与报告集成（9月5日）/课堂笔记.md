# 9月5号 课堂笔记

### 什么是日志

- 生活中：日志类似日记，记录干了什么事
- 编程中：日志记录程序运行时产生的事情
- 一条日志通常包含：
  - 什么时候发生（时间戳）
  - 发生了什么（事件内容）
  - 发生在哪（代码位置）
  - 严重程度（日志级别）

```
2023-08-20 14:25:47 | INFO | user_login.py:15 - 用户[小明]登录成功
2023-08-20 14:26:12 | ERROR | payment.py:42 - 支付失败！余额不足
```

### 为什么不用 print

- print 也能打印，但只能显示在控制台，不方便定位
- 日志可以记录时间、级别、位置，还能存到文件里，方便搜 error

### loguru 日志库

- Python 内置 `logging`（功能弱）
- 第三方库 `loguru`（更强大）
- 安装：`pip install loguru -i 镜像`

### 基本用法

```python
from loguru import logger

logger.debug("调试级别")       # 展示详细信息
logger.info("程序正常运行级别")  # 程序正确时使用
logger.warning("警告级别")      # 警告，程序可能有问题但不影响运行
logger.error("错误信息级别")     # 程序出现了错误
```

### 框架里的应用

- 在任意可能出问题的代码处加 `try...except`，写日志
- 看日志时搜 `error` 定位问题
- 日志信息保存在文件中
- 目标：把日志和测试报告的每个步骤关联起来
  - 设置一个日志缓冲器（日志器），直接复制用即可
  - 见 `HAT/utils/allure_step_logger.py`

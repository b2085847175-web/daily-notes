### 导出项目配置
- 命令：pip freeze > requirements.txt
- 导入命令：pip install -r requirements.txt
- 下载慢就用镜像：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
- 注意：文件名是 requirements.txt，中间有 s；命令要在项目根目录下执行

### YAML语法
- 用 `键: 值` 表示字典，冒号后面要有空格
- 用 `-` 表示列表
- 同一层级要左对齐，缩进只能用空格，不能用 Tab
- 用 `#` 写注释
- 字典里面可以放列表，列表里面也可以放字典
```yaml
# stu.yaml
name: zhangsan
age: 18
list:
  - 1
  - 2
  - 3
```

### 读取文件时的路径转义
- 问题：Windows 路径里的 `\` 可能会被当成转义符，比如 `\t`、`\n`
- 解决方式：前面加 `r`，表示原始字符串，不让 `\` 转义

```python
# 不推荐：路径里有 \t、\n 时可能出错
path = 'F:\test\name.yaml'

# 推荐：加 r，表示按原始字符处理
path = r'F:\test\name.yaml'
```

- 也可以直接把 `\` 换成 `/`：

```python
path = 'F:/test/name.yaml'
```

- 相对路径：
  - `./`：当前目录
  - `../`：上一级目录
  - `../../`：上上级目录
- 注意：相对路径要看运行程序时所在的目录，不是只看代码文件放在哪里

### 为什么要用列表承载数据
- 字典表示一条用例，列表表示一组用例
- `pytest.mark.parametrize` 需要遍历列表，列表里有几条数据，就生成几条用例
- 读出来的字典包一层列表后，即使当前只有 1 条用例，框架也能按统一方式执行

```python
data = [
    {"case_title": "登录成功", "accounts": "youyi", "pwd": "123456"},
    {"case_title": "密码错误", "accounts": "youyi", "pwd": "000000"}
]

@pytest.mark.parametrize("caseinfo", data)
def test_case(caseinfo):
    print(caseinfo)
```

- `caseinfo` 每次接收列表里的一个字典，也就是一条用例

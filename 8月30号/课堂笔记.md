### 设置用例前后置脚本

- 前置脚本：用例执行前准备数据
- 后置脚本：用例执行后清理数据
- 脚本里的 `context` 就是全局变量字典
- 常用 `context.update()` 往全局变量里加数据

在 YAML 用例里写：

```yaml
前置脚本:
  - "context.update({'name': 'youer'})"
后置脚本: ""
```

前面准备好的变量，在用例步骤里用 `{{}}` 渲染：

```yaml
请求数据:
  accounts: '{{name}}'
```

执行顺序：

```text
读取全局变量
-> 执行前置脚本，把数据放进全局变量
-> 渲染用例步骤
-> 执行接口请求
-> 执行后置脚本
```

如果没有前置或后置，直接写成空字符串：

```yaml
前置脚本: ""
后置脚本: ""
```

如果有多个前置动作，写成列表：

```yaml
前置脚本:
  - "context.update({'name': 'youer'})"
  - "context.update({'age': 18})"
```

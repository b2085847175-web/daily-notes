# 8月31号 课堂笔记

### 多用例管理

- 之前的课程只能读取单个 YAML 用例，有问题
- 目标：一次性把文件夹里的 YAML 用例都运行

### 读取多个 YAML 文件

- 判断哪个是「用例」，哪个不是，只读取用例的 YAML 文件
- 规则：`数字开头_分割.yaml`
- 只有符合规则的 YAML 才当作用例执行，不符合的就不读取
- 代码把符合规则的 YAML 文件数据都读出来，一次性运行多个用例

### 接口关联

- 问题：购物车登录失效，因为 token 有问题
- 解决：典型的接口关联
  - 上个接口的返回结果里有下个接口需要的值
  - 从上个接口的返回结果里提取出需要的值，保存在变量中
  - 下个接口用这个变量拿到值

### 接口关联过程

1. 把接口的返回结果数据保存在全局变量
2. 从全局变量里提取需要的值，保存在变量（全局变量）中
3. 下个接口从全局变量中取

### 封装提取数据

- 每次都要提取不同的值，功能经常用、值还经常变化，封装成函数
- 提取的东西可能不同：
  - 提取 token：`$..token`
  - 提取 msg：`$.msg`
  - 提取用户 id：`$.data.id`

参数说明：

- 表达式：`$..token`
- 下标：`2`（有多个值时用下标决定要哪个；只有一个值下标可以没有）
- 变量名：`my_token`（把值保存在变量中）

### 总结

1. 读取一个文件里的多个 YAML 用例文件
2. YAML 之间存在关联时，提取需要的数据保存在全局变量，下个接口从全局变量中拿
